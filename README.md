## The entry

> The lift doors opened on a stranger humming my dead grandmother's lullaby, and for one floor the whole building felt like home.

One sentence, 127 characters (gate: 1–200).

## Why this sentence should win

- **The surprise is the phrasing itself:** the utterly ordinary (a lift, a
  stranger humming) collides with the deeply personal (a dead grandmother's
  lullaby) — a private memory arriving uninvited in a public box.
- **Fresh angle:** no worn image (no puddle holding the sky, no kettle
  clicking). The wonder is that a whole building becomes home for exactly
  one floor, then stops.
- **Grounded and specific:** a lift door, a hum, a lullaby, one floor — the
  moment is small, real, and complete in a single read.
- **Every word works:** no filler, no explanation of its own wonder; the
  sentence trusts the reader to feel the turn.

## How it works

`main.py` writes the sentence to `/output/entry.txt`. It is fully
deterministic: the same bytes on every run, no input, no randomness, no
network.

```sh
python3 main.py
cat /output/entry.txt
```
